   g++ -std=c++11 Source/main.cpp Source/Event.cpp Source/Participant.cpp Source/Organizer.cpp Source/Registration.cpp Source/FileManager.cpp Source/EventSystem.cpp -o Executable/Project
4. Run from the Executable folder so ../Data resolves correctly:
   cd Executable
   ./Project
   (Windows: Project.exe)
5. Try option 1 to view events, option 3 to add a participant, option 7 to register, option 8 to view registrations, then option 0 to save and exit.
6. Re-run and use options 1, 4, and 8 to verify persistence.
